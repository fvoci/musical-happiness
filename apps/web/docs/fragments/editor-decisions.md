# 조각: 편집기 작업에서 스스로 정한 것

작성 2026-11-10 23:52 KST. 편집기의 제품 부품, 수식, 다이어그램, 이모지를 만들면서 물어보지 않고 정한 것을 모은다. 줄마다 **무엇을 / 왜 그 안을 / 다른 안 / 바꾸려면 어디를**의 순서다. 경로는 `apps/web` 기준이다. 설명과 수치는 `docs/spike-editor.md` 10절에, 서버가 맞춰야 할 것은 `docs/fragments/editor-contract.md`에 있다.

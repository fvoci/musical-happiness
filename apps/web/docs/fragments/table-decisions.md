## 그 밖에 정한 것

1. **hover가 없는 기기에서는 행에 "…" 하나만 보이고 "열기"는 그 메뉴의 첫 항목이다.** / 좁은 화면의 제목 열은 160–206px이고 44px 단추 둘을 늘 그리면 제목이 서너 글자만 남는다. / 다른 안: 둘 다 늘 보이게(Q22의 글자 그대로), 또는 "열기"만 보이게(삭제·복제에 닿을 길이 없어진다). / `Row.svelte`의 열기 링크 클래스 `hidden can-hover:flex`를 `flex`로 바꾸면 늘 보인다. 메뉴의 "열기" 줄은 `menus.ts`의 `rowMenu`.
2. **행의 손잡이는 제목 칸 전체다.** 마우스는 누른 채 4px, 손가락은 300ms, 키보드는 제목 칸에서 Space. 점 여섯 개는 hover 기기에서 행을 가리킬 때만 보이는 표시일 뿐이다. 누르고 움직이지 않으면 클릭이고 제목을 고친다. / 따로 44px 손잡이를 둘 자리가 좁은 제목 열에 없고, Tab이 멈추는 곳이 행마다 늘지 않는다. / 다른 안: 따로 둔 손잡이 단추. / `Row.svelte`의 `data-drag-handle`.
3. **끄는 동안 빈자리를 열지 않고 선을 긋는다**(행은 가로선, 열은 세로선). 끌리는 것은 제자리에 흐리게 남고 작은 딱지가 포인터를 따라간다. 키보드로 나르는 동안에는 행(열은 머리글만)이 놓일 자리로 옮겨 선다. / 표에서 행 하나만큼 빈자리가 열리면 그 아래 수백 행이 밀린다. / 다른 안: 칸반처럼 빈자리. / `table.svelte.ts`의 `rowMarker`·`columnMarker`·`shownLists`·`headerColumns`, 선의 생김새는 `host.ts`의 `DROP_LINE_ROW`와 `HeaderCell.svelte`.
4. **한 번에 한 칸만 편집기다.** 모든 칸은 `PropertyValue`의 `display`로 그리고, 누른 칸만 `edit` + `startOpen`으로 바꾼다. 끝났는지는 그 칸의 DOM에서 읽는다: 글 칸은 초점이 칸을 떠나면, 선택기는 방아쇠의 `aria-expanded`가 참에서 거짓이 되면. / 속성 부품에 "끝났다"는 콜백이 없고, 공용 부품을 고치면 카드 상세 작업과 겹친다. / 다른 안: `PropertyValue`에 `onDone`을 더한다(더 깔끔하다. 합친 뒤의 후보). / `cell-editing.svelte.ts`.
5. **체크박스 칸은 편집 상태가 없다.** 표시로 그리고 칸이 누름을 받아 바로 바꾼다(키보드는 Space·Enter). / 편집 모드의 체크박스는 칸마다 Tab이 멈추는 단추가 된다. / 화면 낭독기에는 안의 체크박스가 "사용할 수 없음"으로 읽힌다(표시 모드가 `disabled`라서). 공용 부품에 "읽기 전용이지만 꺼지지 않은" 표시가 생기면 바꾼다. / `Row.svelte`, `table.svelte.ts`의 `host.activate`.
6. **칸에서 선택지를 만들거나 이름·색을 바꾸거나 지우지 않는다**(있는 선택지를 고르기만). / 속성 정의를 바꾸는 일은 카드 상세의 것이라는 지시의 연장으로 봤다. / 다른 안: 원본처럼 칸에서도. / `Row.svelte`의 편집 `PropertyValue`에 `onCreateOption` 등을 넘기면 된다.
7. **열의 수치**: 최소 100px(원본과 같다), 최대 800px, 너비가 저장돼 있지 않은 열은 150px(원본은 최솟값 100px. 날짜가 잘린다), 손잡이의 화살표 한 번 16px, 메뉴 한 번 48px. / `columns.ts`의 `TABLE_SETTINGS` 한 곳.
8. **너비는 "지금 보이는 너비"에서 바꾼다.** 제목 열이 절반 제한에 걸려 저장된 값보다 좁게 보일 때 "더 좁게"는 보이는 너비에서 줄이고, "더 넓게"는 아무것도 하지 않는다(보이지 않는 값만 커지지 않게). 손잡이를 끌 때도 같다. / `column-resize.svelte.ts`.
9. **정렬 메뉴는 그 열 하나로 뷰의 정렬을 바꾼다**(다른 정렬은 사라진다. 원본과 같다). 정렬을 푸는 항목은 머리글 메뉴에 없다(뷰 머리글의 일). / `table.svelte.ts`의 `headerActions`.
10. **그룹 접기**: 고칠 수 있는 사람은 뷰에 저장(`collapsedOptionIds`), 읽기만 하는 사람은 이번 방문 동안만(저장하지 않는다). 값 없는 그룹도 접을 수 있다(원본은 못 접었다. `collapsedOptionIds`에 `''`가 들어간다). / 다른 안: 읽기만 하는 사람은 못 접게(원본). / `table.svelte.ts`의 `toggleGroup`.
11. **그룹과 새 카드**: 그룹 머리의 "+"와 그룹 맨 아래의 "+ 새로 만들기"가 그 그룹의 값으로 만든다. 접힌 그룹의 "+"는 그룹을 펴고 만든다. 만든 사람·고친 사람으로 묶인 뷰(값을 정할 수 없다)에서는 그룹별 추가가 없고 표 맨 아래에 하나만 있다. 새 카드는 뷰의 필터가 요구하는 값도 받는다(조립 파일의 `addCard`와 같게). / `table.svelte.ts`의 `addCard`·`canAddTo`·`canAddLoose`.
12. **행 메뉴**: 삭제는 묻지 않는다(실행 취소가 된다). 삭제 뒤 초점은 그 자리에 온 이웃 행의 제목 칸, 복제 뒤 초점은 새 행의 제목 칸(원본은 새 카드를 열었다). 링크 복사는 화면 낭독기에만 "복사되었습니다!"를 알린다(보이는 표시는 없다). / `table.svelte.ts`의 `#deleteCard`·`#duplicateCard`·`#copyLink`.
13. **계산**: 저장된 값이 없으면 제목 열은 "개수", 나머지는 없음(원본과 같다). 그 종류가 가질 수 없는 계산이 저장돼 있으면 없음으로 본다. 메뉴는 `propertyBehavior(type).calculationOptions`에 **체크박스의 넷(체크된 개수 등)과 날짜의 셋(가장 이른 날짜 등)을 테이블에서 보탰다**(원본의 표가 그랬다. `lib/logic/properties.ts`에는 없다). 원본에 메시지가 없던 네 계산(빈 값 개수 등)의 이름을 새로 지었다. / `calculation-names.ts`의 `TABLE_EXTRAS`와 `NAMES`, 문구는 `messages-own/table/`.
14. **Ctrl/⌘+Z(Shift와 함께면 다시 실행)를 표가 직접 받는다.** / 실행 취소를 누를 곳이 기준 커밋에 없어서(셸 작업의 몫) 표 안에서 되게 했다. 입력 칸 안에서는 가로채지 않고, 이미 처리된 이벤트(`defaultPrevented`)는 건드리지 않고, 처리하면 전파를 멈춘다. / **셸의 단축키가 들어오면 지운다**: `Table.svelte`의 `onKeyDown` 안 "Until the shell has its own shortcut" 분기. 지워도 종단 테스트는 셸의 단축키로 통과해야 한다(칸에 초점을 두고 Ctrl+Z를 누른다).
15. **키보드**: 표는 Tab이 한 번 멈추는 곳이다(초점이 있던 칸). 화살표로 칸 사이, Home·End로 행의 끝, Ctrl+Home·End로 표의 끝, Enter·F2로 편집(머리글은 메뉴, 계산 칸은 메뉴, 그룹 머리는 접기, "+ 새로 만들기"는 만들기), Escape로 나오기, 체크박스는 Space. 칸 안의 단추("열기", "…", 너비 손잡이, 그룹의 접기·"+")는 그 칸이 멈추는 곳일 때만 Tab으로 닿는다. 글자를 치면 바로 편집이 시작되는 것은 없다. `tabindex`는 상태로 그리지 않고 초점을 따라 DOM에서 옮긴다(수백 행을 다시 그리지 않으려고). / `grid-focus.ts`, `Table.svelte`의 `onKeyDown`.
16. **읽기만 하는 보드**: 머리글 메뉴·너비 손잡이·열과 행의 끌기·"+ 새로 만들기"·계산 메뉴가 없고 칸을 눌러도 편집기가 되지 않는다. 행 메뉴에는 "열기"와 "링크 복사"만 남는다. 표에 `aria-readonly`. / 각 부품의 `canEdit`.
17. **큰 표**: 화면 밖의 행은 `content-visibility: auto`로 배치와 칠하기를 건너뛴다(한 번도 안 그려진 행은 36px, 넉넉한 밀도 44px로 친다). 행의 "…" 메뉴는 처음 누를 때 만든다. 행의 "…"와 점 아이콘은 공용 `IconButton`·아이콘 부품이 아니라 같은 모양의 평범한 요소다(행마다 부품 하나의 값이 든다. 이름은 `aria-label`로 같다). 가상 스크롤은 하지 않았다. / `host.ts`의 `ROW_SKIPPED`·`MORE_BUTTON`, `Row.svelte`.
18. **행 사이의 선은 행이 긋고, 고정된 제목 칸은 위아래 1px를 칠하지 않는다.** / 고정된 칸은 따로 그려지는 층이라 배율 3에서 1px 어긋나 이웃 행의 선을 덮었다(스크린샷에서 발견). / `Row.svelte`의 `border-y-transparent bg-clip-padding`.
19. **끌어 놓은 자리의 번역**: 저장소의 `dropCards`는 `index`를 "그 그룹의 모든 카드(필터·검색에 가려진 것 포함) 가운데의 자리"로 센다. 표는 보이는 행 가운데의 자리를 알므로 넘기기 전에 바꾼다(위에 보이는 행의 바로 뒤). / 그대로 넘기면 필터가 걸린 뷰에서 엉뚱한 자리에 놓인다. / `drop-index.ts`. **칸반도 같은 변환이 필요하다. 공용으로 내릴 후보**(저장소가 "보이는 이웃"을 받게 하는 편이 낫다).
20. **열 머리글에 속성 종류의 아이콘이 없다**(이름만). 숫자 열을 오른쪽에 맞추지도 않았다. / 지시에 없다. / `HeaderCell.svelte`, `Row.svelte`.
21. **오른쪽에서 왼쪽으로 쓰는 화면**: 논리 속성(`start`, `border-e`)을 쓰고 손잡이와 화살표의 방향을 뒤집지만, 화면으로 확인하지 않았다.

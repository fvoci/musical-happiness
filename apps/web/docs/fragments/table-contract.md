# 테이블 뷰: 서버의 계약에 관해 (조각 문서)

작성: 2026-11-11 00:11 KST. 부른 쪽이 `contract-assumptions.md`에 합친다.

테이블 뷰는 새 읽기·쓰기를 지어내지 않았다. 쓰는 것은 모두 저장소(`lib/state`)에 이미 있는 것이다: 뷰의 `fields` 고치기(`setViewFields`), 카드의 속성·제목 고치기, 카드 만들기·복제·삭제, `dropCards`.

서버가 알아야 할 것은 뷰의 `fields`에 들어가는 값의 모양뿐이다. 원본과 다른 곳을 굵게 적는다.

| 필드                 | 테이블이 쓰는 값                                                                                                                               | 원본과                                                                                                                                                          |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `columnWidths`       | 속성 id → 정수 px(100–800). 제목 열의 키는 `__title`                                                                                           | 같다(원본은 상한이 없다)                                                                                                                                        |
| `columnCalculations` | 속성 id(제목 열은 `__title`) → 계산의 이름(`count`, `sum`, `countChecked`, `none` 등 `lib/logic/calculations.ts`의 `CALCULATION_IDS`와 `none`) | 같다                                                                                                                                                            |
| `visiblePropertyIds` | 열의 순서. 숨기면 빠진다. 보드에 없는 속성의 id는 지우지 않고 뒤에 남긴다                                                                      | 같다                                                                                                                                                            |
| `sortOptions`        | 머리글 메뉴는 `[{propertyId, reversed}]` 하나로 갈아 쓴다. 제목 열은 `__title`                                                                 | 같다                                                                                                                                                            |
| `collapsedOptionIds` | 접은 그룹의 선택지 id. **값 없는 그룹을 접으면 빈 문자열 `''`이 들어간다**                                                                     | 다르다: 원본은 값 없는 그룹을 접지 못했다. 서버가 이 목록의 원소를 검사한다면 `''`를 받아야 한다(`visibleOptionIds`·`hiddenOptionIds`에는 원본도 `''`를 넣는다) |
| `cardOrder`          | 행을 끌면 `dropCards`가 보드의 모든 카드 id를 수동 순서로 다시 쓴다                                                                            | 저장소의 동작(이번에 바꾼 것이 아니다)                                                                                                                          |

카드를 만들 때는 `properties`에 뷰의 필터가 요구하는 값과 그룹의 값을 담아 보낸다(빈 값은 넣지 않는다).
